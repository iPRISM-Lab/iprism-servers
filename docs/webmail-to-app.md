## Αναλυτικές Οδηγίες ανά Εφαρμογή

### 1. Ρύθμιση Outlook σε Windows

**Βήμα 1: Πρόσβαση στη δημιουργία λογαριασμού**
- Αν δεν υπάρχει λογαριασμός: Η εφαρμογή θα ζητήσει άμεσα προσθήκη
- Αν υπάρχει ήδη λογαριασμός: `Αρχείο (File)` → `Προσθήκη λογαριασμού (Add Account)` → `Διαχείριση προφίλ (Manage profiles)` → `Λογαριασμοί ηλεκτρονικού ταχυδρομείου (Email accounts)` → `Δημιουργία (Create)`

**Βήμα 2: Εισαγωγή ρυθμίσεων**
- Επιλέξτε: `Μη αυτόματη ρύθμιση… (Let me set up my account manually)` → `Επόμενο (Next)`
- Επιλέξτε: `POP ή IMAP` → `Επόμενο (Next)`
- Πληκτρολογήστε τις κοινές ρυθμίσεις (IMAP, SMTP, θύρες, STARTTLS)
- Πατήστε `Περισσότερες ρυθμίσεις… (Advanced options…)`

**Βήμα 3: Πρόσθετες ρυθμίσεις**
- Καρτέλα `Διακομιστής εξερχομένων (Servers)`: Τσεκάρετε `Ο διακομιστής εξερχομένων (SMTP) απαιτεί έλεγχο ταυτότητας`
- Καρτέλα `Για προχωρημένους (Advanced)`: Συμπληρώστε υπόλοιπες ρυθμίσεις (θύρες)
- Πατήστε `OK`

**Βήμα 4: Ολοκλήρωση**
- Πατήστε `Επόμενο (Next)` → `Τέλος (Finish)`

---

### 2. Ρύθμιση Thunderbird σε Windows

**Βήμα 1: Νέος λογαριασμός**
- `Menu (≡)` → `Νέος λογαριασμός (New)` → `Email` → `Ρύθμιση υπάρχουσας διεύθυνσης email (Existing Mail Account)`

**Βήμα 2: Συμπλήρωση στοιχείων**
- `Όνομα:` (ό,τι θέλετε να εμφανίζεται ως αποστολέας)
- `Email:` username@uth.gr
- `Κωδικός:` (ο κωδικός σας)
- Πατήστε `Χειροκίνητη ρύθμιση (Manual config)`
- Καταχωρήστε τις κοινές ρυθμίσεις (IMAP, SMTP, θύρες, STARTTLS)

**Βήμα 3: Ολοκλήρωση**
- Πατήστε `Δοκιμή ξανά (Re-test)`
- Αφού ελεγχθούν επιτυχώς οι ρυθμίσεις → `Τέλος (Done)`

---

### 3. Ρύθμιση Gmail σε Android

**Σημαντικό:** Η εφαρμογή Gmail μπορεί να διαχειριστεί και μη-Google λογαριασμούς μέσω χειροκίνητης ρύθμισης.

**Βήμα 1: Προσθήκη λογαριασμού**
- Άνοιξε την εφαρμογή Gmail
- Πάνω δεξιά: πατήστε το εικονίδιο λογαριασμού → `Προσθήκη άλλου λογαριασμού (Add another account)`
- Επιλέξτε τύπο λογαριασμού: `Άλλος (Other)`
- Πληκτρολογήστε `username@uth.gr`
- Επιλέξτε `Χειροκίνητη ρύθμιση (Manual setup)`

**Βήμα 2: Εισαγωγή ρυθμίσεων**
- Πληκτρολογήστε τις κοινές ρυθμίσεις (IMAP, SMTP, θύρες, STARTTLS, όνομα χρήστη, κωδικός)

**Βήμα 3: Ολοκλήρωση**
- Διαλέξτε ρυθμίσεις συγχρονισμού (συχνότητα, ειδοποιήσεις, κλπ.)
- Πατήστε `Επόμενο (Next)` για να μεταβείτε στο γραμματοκιβώτιό σας

---

### 4. Ρύθμιση Outlook σε Android

**Προσοχή!** Πριν ρυθμίσετε, εγκαταστήστε την πιο πρόσφατη έκδοση από το Google Play.

**Βήμα 1: Προσθήκη λογαριασμού**
- Ανοίξτε το Outlook
- Πάνω αριστερά: εικονίδιο λογαριασμού ή `Menu` → `+` → `Προσθήκη Λογαριασμού (Add Account)`
- (Αν υπάρχουν άλλοι λογαριασμοί, μην τους επιλέξετε)
- Πατήστε `Συνέχεια` και πληκτρολογήστε `username@uth.gr`
- Πατήστε `Συνέχεια`

**Βήμα 2: Ρυθμίσεις για προχωρημένους**
- Επιλέξτε `IMAP`
- Ενεργοποιήστε στο κάτω μέρος: `Ρυθμίσεις για προχωρημένους`
- Πληκτρολογήστε τις κοινές ρυθμίσεις (IMAP, SMTP, θύρες, STARTTLS)

**Βήμα 3: Ολοκλήρωση**
- Πατήστε `Done` / `Proceed`
- Ο λογαριασμός θα συγχρονιστεί αμέσως

### 5. Ρύθμιση Apple Mail σε iOS

**Βήμα 1: Πρόσβαση**
- `Ρυθμίσεις` → `Mail` → `Λογαριασμοί` → `Προσθήκη λογαριασμού` → `Άλλο` → `Προσθήκη λογαριασμού Mail`

**Βήμα 2: Βασικά στοιχεία**
- Πληκτρολογήστε: `Ονοματεπώνυμο`, `email (username@uth.gr)`, `Κωδικός`
- `Περιγραφή:` π.χ. "Ιδρυματικό email"
- Πατήστε `Επόμενο`

**Βήμα 3: Ρυθμίσεις διακομιστή**
- Όταν ζητηθεί, επιλέξτε `IMAP`
- Συμπληρώστε τις κοινές ρυθμίσεις (IMAP, SMTP, θύρες, STARTTLS)

**Βήμα 4: Ολοκλήρωση**
- Πατήστε `Επόμενο` → `Αποθήκευση`
